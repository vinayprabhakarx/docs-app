## Overview

MongoDB is the premier document-oriented NoSQL database, offering horizontal scalability, flexible schema design, and high performance for unstructured or semi-structured data. This checklist covers core MongoDB fundamentals, CRUD operations, aggregation pipelines, indexing strategies, and integration with Spring Boot via Spring Data MongoDB.

> **Tip:** Practice writing queries both in MongoDB Compass / Shell and within Spring Data repositories using `MongoRepository` and `MongoTemplate`.
