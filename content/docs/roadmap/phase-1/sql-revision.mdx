## Overview

This checklist covers relational database fundamentals, complex query authoring, window functions, and schema design principles essential for backend engineering.

> **Tip:** Practice writing window functions (`ROW_NUMBER`, `DENSE_RANK`, `LEAD`/`LAG`) and CTEs (`WITH`) on sample datasets to ensure quick problem solving during SQL interviews.
