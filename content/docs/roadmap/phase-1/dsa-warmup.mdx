## Overview

This checklist focuses on warming up your Data Structures and Algorithms problem-solving skills. Spend time analyzing algorithmic complexity, implementing core sorting logic by hand, and solving standard array/string patterns.

> **Target:** Solve a minimum of 25 problems (Easy to Medium difficulty) spanning Two-Pointer, Sliding Window, Prefix Sum, Kadane's, and Binary Search.

---

## Complexity Analysis

- [ ] Big O — O(1), O(log n), O(n), O(n log n), O(n²), O(2ⁿ)
- [ ] Space complexity
- [ ] Analyze loops, nested loops, recursion
