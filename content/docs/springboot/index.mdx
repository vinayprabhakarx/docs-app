sidebar to navigate, grouped into **Beginner**, **Intermediate**, and
**Advanced** sections.

Go roughly in order the first time through — later topics assume earlier
ones (e.g. Testing assumes you already know the Controller → Service →
Repository layering from the Beginner/Intermediate sections).
